# refs/

Reference FASTA sequences generated by `simulation/sequence_generator.py` (one file per 4-mer
end-motif, seeded from `MASTER_SEED` for reproducibility). `motif_manifest.tsv` is the manifest
written alongside them and is tracked here for reference.

The generated `.fa` files themselves are large (~54MB total) and reproducible, so they live
outside the repo at:

    ../neuromorphic_liquid_biopsy_data/refs/

Not tracked in git (see `.gitignore`: `*.fa`).
